# Anime Recorder

밖에서 **폰으로 집 PC의 OBS 녹화를 조작하는 전용 앱**입니다.
녹화는 PC에서 원본 화질로 되고, 폰은 리모컨 역할만 합니다.

- **원터치 녹화**: 주소를 넣고 "녹화 시작"을 누르면 PC에서 페이지가 열리고 OBS가 녹화를 시작합니다. 자동 정지 시간도 정할 수 있어요 (예: 25분).
- **실시간 미리보기**: 지금 녹화되는 화면을 폰에서 2~3초 간격으로 확인합니다. 원격 데스크톱이 필요 없어요.
- **★ 장면 표시**: 보다가 쓸 만한 장면에서 버튼을 누르면 그 시점이 기록됩니다. 빠른 라벨(명장면/웃김/액션 등)과 "구간 시작/끝"도 있습니다.
- **자동 클립**: 녹화가 끝나면 표시한 장면을 ffmpeg로 **재인코딩 없이** 잘라서 `녹화폴더/clips`에 저장합니다. 편집할 때 클립만 끌어다 쓰면 됩니다.
- **녹화 격리**: 녹화하는 동안 PC로 다른 작업(게임, 유튜브, 작업 프로그램)을 해도 녹화본에 섞이지 않습니다. [자세히](#녹화-격리-다른-작업을-해도-녹화본은-깨끗하게)
- **예약 녹화**: 매주 요일 반복이나 특정 날짜 1회.
- **기록**: 녹화마다 표시한 장면과 클립 결과를 모아서 보여주고, 라벨 수정, 다시 자르기도 됩니다.

```
[폰: 전용 앱(PWA)] ──Tailscale(암호화)──▶ [집 PC: recorder 서버] ──WebSocket──▶ [OBS]
                                                    └── ffmpeg로 클립 자르기
```

> DRM이 걸린 OTT(넷플릭스 등)는 OBS로 캡처하면 검은 화면이 나옵니다. 이 앱은 DRM을 우회하지 않으며, DRM이 없는 소스용입니다.

## 📱 안드로이드 앱 (추천)

Artemis처럼 **PC 목록에서 고르면 바로 연결되는 전용 앱**입니다.

**설치**: 폰에서 [Releases의 "Android 앱 (최신 빌드)"](https://github.com/Hastile/anime_recorder/releases/tag/android-latest)를 열고 `AnimeRecorder.apk`를 받아 설치합니다.
("출처를 알 수 없는 앱 설치"를 허용하라고 나오면 허용하세요. 새 빌드는 기존 앱 위에 그대로 업데이트됩니다.)

**처음 연결 (집에서 한 번)**
1. PC에서 `start.bat`을 실행해 둡니다. (Windows 방화벽 창이 뜨면 **개인 네트워크 허용**)
2. 앱을 열면 "같은 와이파이에서 찾은 PC"에 PC가 나타납니다 → **연결**
3. PC 화면에 뜬 **4자리 PIN**을 앱에 입력하면 끝.
   이때 PC의 Tailscale 주소도 자동으로 저장되므로, **밖에서는 폰의 Tailscale만 켜면 그대로 연결됩니다.**

**쓰는 법**
- PC 카드를 누르면 녹화 화면이 열립니다 (초록 점: 같은 와이파이 / 외부(Tailscale) 표시).
- 녹화가 시작되면 **알림에 리모컨**이 생깁니다: `★ 표시` · `구간 시작/끝` · `■ 정지`(실수 방지: 두 번 눌러야 정지).
  폰으로 다른 앱에서 영상을 보면서도, 잠금화면에서도 누를 수 있어요.
- **빠른 설정 타일**: 상단바를 내리고 연필(편집) → `★ 장면 표시` 타일을 추가하면, 탭 한 번으로 표시됩니다.
- PC 카드를 길게 누르면 이름 변경, 주소 추가, 삭제.

> 자동 검색이 안 되면 `PC 추가`에서 PC의 IP(예: `192.168.0.10`)를 직접 넣으세요.
> 앱을 직접 빌드하려면 `android/` 폴더를 Android Studio로 열면 됩니다.

## 1. PC 설정 (Windows, 한 번만)

1. **Python 3.11 이상**을 설치합니다 (설치할 때 "Add to PATH"에 체크).
2. **ffmpeg**를 설치합니다: PowerShell에서 `winget install Gyan.FFmpeg`
3. **OBS 설정**
   - `도구 → WebSocket 서버 설정`에서 **WebSocket 서버 활성화**를 켭니다. 포트(4455)와 비밀번호를 확인해 두세요.
   - `설정 → 출력 → 녹화`
     - 녹화 형식: **mkv** (녹화가 중간에 끊겨도 파일이 살아남습니다)
     - 인코더: NVENC/AMF/QSV 같은 하드웨어 인코더, 품질 CQP 18~20 정도
     - **키프레임 간격: 1초**. 무손실 자르기는 키프레임 단위로 잘리기 때문에 짧을수록 정확합니다.
   - 장면에는 **윈도우 캡처** 소스(이름: `녹화 창`)와 **응용 프로그램 오디오 캡처** 소스(이름: `녹화 창 소리`)를 넣어 둡니다.
     창은 아무거나 골라 두면 됩니다. 녹화할 때마다 앱이 녹화용 창으로 바꿔 줍니다.
     - 윈도우 캡처의 캡처 방식은 **Windows 10 (1903 이상)**으로 둡니다. 다른 창에 가려져도 캡처됩니다.
     - **화면 캡처(디스플레이 캡처)는 쓰지 마세요.** 쓰면 다른 작업 화면이 녹화됩니다.
     - 믹서에서 **데스크톱 오디오와 마이크는 음소거**합니다.
4. 이 폴더를 PC에 내려받고, `config.example.toml`을 `config.toml`로 복사해서 OBS 비밀번호를 적습니다.
5. **`start.bat`을 더블클릭**합니다. 처음 실행할 때는 필요한 패키지를 알아서 설치합니다.
   창에 나오는 **접속 토큰**을 메모해 두세요 (`data/token.txt`에도 저장됩니다).
6. 절전 모드와 모니터 꺼짐을 해제합니다 (`설정 → 시스템 → 전원`). 모니터가 꺼지면 캡처가 검게 나올 수 있어요.

> 윈도우 시작 시 자동 실행: `Win+R` → `shell:startup` → `start.bat`의 바로가기를 넣어 두세요.

## 2. 밖에서 접속: Tailscale (무료, 포트 열기 불필요)

1. PC와 폰에 [Tailscale](https://tailscale.com/download)을 설치하고 같은 계정으로 로그인합니다.
2. PC의 PowerShell에서 한 번 실행합니다:
   ```
   tailscale serve --bg 8765
   ```
   그러면 `https://<PC이름>.<tailnet>.ts.net` 주소가 생깁니다 (`tailscale serve status`로 확인).
   HTTPS여야 폰에서 **앱으로 설치**하는 기능이 정상 동작합니다.
3. 폰 브라우저에서 그 주소를 열고 토큰을 입력합니다.
4. **홈 화면에 추가**하면 전용 앱처럼 쓸 수 있습니다.
   - 안드로이드 크롬: 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
   - 아이폰 사파리: 공유 → "홈 화면에 추가"

> 같은 와이파이에서는 서버 창에 나온 `http://192.168.x.x:8765`로도 접속됩니다.
> 공유기 포트포워딩으로 인터넷에 직접 여는 것은 권장하지 않습니다.

## 3. 사용 흐름

1. 밖에서 앱 열기 → 주소, 제목 입력 → 자동 정지 "25분" → **● 녹화 시작**
2. 폰으로 같은 에피소드를 보면서 쓸 장면이 나오면 **★ 지금 표시** (기본: 그 시점 10초 전 ~ 5초 후)
   - 긴 장면은 **구간 시작 → 구간 끝**
3. 자동 정지되거나 ■ 정지를 누르면 표시한 장면이 자동으로 잘려 `clips/` 폴더에 저장됩니다.
4. 집에 와서 편집 프로그램에 `clips/` 폴더만 불러오면 끝.

> 폰으로 보는 영상과 PC 녹화는 시작 시점이 약간 다를 수 있습니다. 앞뒤 여유(`pre_seconds`/`post_seconds`)를 넉넉히 두면 편합니다.

OBS에서 직접 녹화를 시작한 경우에도 앱에서 ★를 누르면 자동으로 세션이 만들어집니다.

## 녹화 격리: 다른 작업을 해도 녹화본은 깨끗하게

녹화를 걸어 두고 같은 PC로 다른 일을 해도 녹화본에는 녹화용 창의 화면과 소리만 들어갑니다.

| 문제 | 해결 |
|---|---|
| 내가 쓰는 브라우저의 탭이나 소리가 섞임 | 녹화 전용 브라우저를 **별도 프로필, 독립 창**으로 띄웁니다. 평소 브라우저와 완전히 다른 프로세스라 섞일 일이 없어요. |
| 다른 창으로 가리면 영상이 멈추거나 검게 나옴 | 크롬이 가려진 창의 그리기와 재생을 줄이는 기능(occlusion, 백그라운드 절전)을 끄고 실행합니다. OBS 윈도우 캡처(WGC)는 가려진 창도 캡처합니다. |
| 키보드 ⏯ 미디어 키를 누르면 녹화 영상이 멈춤 | 녹화용 브라우저에서는 미디어 키와 미디어 컨트롤 처리를 끕니다. |
| 녹화를 시작하면 브라우저가 튀어나와 작업을 방해함 | 창이 뜨면 바로 **맨 뒤로 보내고 작업하던 창으로 포커스를 돌려줍니다.** |
| 실수로 녹화 창을 최소화하면 캡처가 멈춤 | 녹화 중 최소화를 감지하면 포커스를 뺏지 않고 **맨 뒤에 다시 복원합니다.** |
| OBS가 엉뚱한 창이나 소리를 잡음 | 띄운 창을 OBS의 윈도우 캡처 / 응용 프로그램 오디오 캡처 소스에 **정확히 지정합니다.** |
| 설정 실수 (디스플레이 캡처, 데스크톱 오디오 켜짐 등) | 앱의 **"녹화 격리 점검"**에서 경고합니다. |

**처음 한 번**: 녹화 전용 브라우저는 평소 브라우저와 프로필이 달라서 로그인이 따로 필요합니다.
앱에서 사이트 주소로 녹화를 한 번 시작해 PC에 뜬 창에서 로그인해 두면, 그 뒤로는 계속 유지됩니다 (`data/browser-profile`).

**팁**
- 평소 **크롬**을 쓴다면 녹화는 **엣지**로 하세요 (`browser.executable`). 실행 파일 자체가 달라서 가장 확실합니다.
- 보조 모니터가 있다면 `window_position`으로 녹화 창을 그쪽에 두면 편합니다.
- 영상 플레이어를 창 크기에 맞추려면 사이트의 "넓게 보기"를 쓰거나, OBS 소스를 크롭하면 됩니다. 사이트마다 한 번만 맞춰 두면 됩니다.
- 남는 한계: 고사양 게임처럼 GPU를 많이 쓰는 작업을 같이 하면 녹화가 끊길 수 있습니다. 그럴 때는 OBS 하드웨어 인코더(NVENC 등)를 쓰세요.

## 설정 (`config.toml`)

| 항목 | 설명 |
|---|---|
| `obs.video_source` / `audio_source` | 녹화 창에 자동으로 연결할 OBS 소스 이름 |
| `browser.isolated` | 녹화 전용 브라우저(별도 프로필, 독립 창) 사용 (권장) |
| `browser.executable` | 녹화에 쓸 브라우저. 비우면 크롬 → 엣지 순서로 찾음 |
| `browser.window_size` / `window_position` | 녹화 창 크기와 위치 |
| `browser.send_to_back` | 창을 띄운 뒤 맨 뒤로 보내고 포커스 복귀 |
| `browser.close_on_stop` | 녹화가 끝나면 녹화 창 닫기 |
| `browser.wait_seconds` | 페이지를 연 뒤 녹화 시작까지 기다리는 시간 |
| `clips.pre_seconds` / `post_seconds` | ★ 표시 기준 앞뒤로 자를 길이 |
| `clips.reencode` | `false`: 무손실 고속 (키프레임 단위) / `true`: 프레임 단위로 정확하지만 느림 |
| `clips.auto_export` | 녹화가 끝나면 자동으로 클립 만들기 |
| `clips.quick_labels` | ★ 아래 빠른 라벨 버튼 |

## 개발

```bash
pip install -r requirements.txt pytest httpx
python -m recorder --demo     # OBS 없이 UI 확인 (가짜 녹화기)
python -m pytest
```

- `recorder/server.py`: HTTP API (모든 `/api/*`는 `Authorization: Bearer <토큰>` 필요)
- `recorder/core.py`: 녹화, 마커, 자동 정지, 예약 실행
- `recorder/obs.py`: OBS WebSocket v5 제어
- `recorder/isolation.py`: 녹화 전용 브라우저, 창 제어(Win32), OBS 격리 점검
- `recorder/clips.py`: ffmpeg 자르기
- `recorder/pairing.py`: 앱 연결 (PC 정보, LAN 자동 검색, PIN 페어링)
- `recorder/static/`: 리모컨 웹 화면 (안드로이드 앱 안에서도 이 화면을 씀)
- `android/`: 안드로이드 앱 (Kotlin, Jetpack Compose). `.github/workflows/android.yml`이 APK를 빌드해 Releases에 올림
