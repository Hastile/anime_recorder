# Anime Recorder

**폰으로 보던 페이지를 PC에서 원본 화질로 녹화**하는 도구입니다.

폰 브라우저에서 보다가 **공유 → PC에서 녹화**를 누르면:
1. 집 PC가 같은 페이지를 녹화 전용 브라우저로 엽니다.
2. 영상을 찾아 **정한 위치로 이동**하고, **창에 꽉 채운 뒤** (사이트 메뉴/댓글 없이 영상만)
3. OBS 녹화를 시작하고 재생합니다.
4. **영상이 끝나면 녹화도 자동으로 멈추고**, 파일 이름을 **페이지 제목**(또는 정한 이름)으로 저장합니다.

주소를 따로 입력할 필요가 없고, 녹화 중에는 폰에서 일시정지, 10초 이동, 정지, 파일 이름 변경을 할 수 있습니다.
녹화하는 동안 PC로 다른 작업을 해도 녹화본에 섞이지 않습니다 ([녹화 격리](#녹화-격리-다른-작업을-해도-녹화본은-깨끗하게)).

```
[폰 브라우저] ─공유→ [Anime Recorder 앱] ─(와이파이 / Tailscale)→ [집 PC 서버]
                                                     ├─ 녹화 전용 브라우저 조작 (Playwright)
                                                     └─ OBS 녹화 (WebSocket)
```

> DRM이 걸린 OTT(넷플릭스 등)는 OBS로 캡처하면 검은 화면이 나옵니다. 이 도구는 DRM을 우회하지 않으며, DRM이 없는 소스용입니다.

## 📱 폰 앱

### 안드로이드 앱 (추천)
폰에서 [Releases의 "Android 앱 (최신 빌드)"](https://github.com/Hastile/anime_recorder/releases/tag/android-latest)를 열고 `AnimeRecorder.apk`를 받아 설치합니다.

> **"잠재적으로 유해한 앱" / Play 프로텍트 경고가 뜨면**: 플레이 스토어 밖에서 받은 개인 제작 앱이라 뜨는 경고입니다.
> 경고 창에서 "세부정보 더보기" → **"그래도 설치"**를 누르세요.
> 그 버튼이 없으면 Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → "Play 프로텍트로 앱 검사"를 잠시 끄고 설치한 뒤 다시 켜세요.

**처음 연결 (집에서 한 번)**
1. PC에서 `start.bat`을 실행해 둡니다. (Windows 방화벽 창이 뜨면 **개인 네트워크 허용**)
2. 앱을 열면 "같은 와이파이에서 찾은 PC"에 PC가 나타납니다 → **연결**
3. PC 화면에 뜬 **4자리 PIN**을 앱에 입력하면 끝.
   이때 PC의 Tailscale 주소도 자동으로 저장되므로, **밖에서는 폰의 Tailscale만 켜면 그대로 연결됩니다.**

**쓰는 법**
- 폰 브라우저(크롬, 삼성 인터넷 등)에서 영상 페이지를 보다가 **공유 → PC에서 녹화**
- 앱이 열리고 주소와 제목이 채워져 있습니다. 필요하면 **시작 위치**(예: `12:34`)와 **파일 이름**을 정하고 **● PC에서 녹화 시작**
- 녹화 중에는 알림에도 `⏸ 일시정지` · `■ 정지하고 저장`(실수 방지: 두 번 눌러야 정지) 버튼이 있습니다.
- **녹화본** 탭에서 지난 녹화의 이름을 바꾸면 PC의 파일 이름도 바뀝니다.

### 앱 없이 (아이폰 등)
Tailscale 주소(`https://<PC이름>.<tailnet>.ts.net`, 아래 참고)를 폰 브라우저로 열고 **홈 화면에 추가**하세요.
안드로이드 크롬에서 "앱 설치"로 추가하면 공유 메뉴에도 나타납니다. 아이폰은 주소를 복사해서 붙여 넣으면 됩니다.

## 1. PC 설정 (Windows, 한 번만)

1. **Python 3.11 이상**을 설치합니다 (설치할 때 "Add to PATH"에 체크).
2. **OBS 설정**
   - `도구 → WebSocket 서버 설정`에서 **WebSocket 서버 활성화**를 켭니다. 포트(4455)와 비밀번호를 확인해 두세요.
   - `설정 → 출력 → 녹화`: 녹화 형식 **mkv**(녹화가 끊겨도 파일이 살아남음), 하드웨어 인코더(NVENC/AMF/QSV), 품질 CQP 18~20 정도
   - 장면에 **윈도우 캡처** 소스(이름: `녹화 창`)와 **응용 프로그램 오디오 캡처** 소스(이름: `녹화 창 소리`)를 넣어 둡니다.
     창은 아무거나 골라 두면 됩니다. 녹화할 때마다 녹화용 창으로 자동으로 바꿔 줍니다.
     - 윈도우 캡처의 캡처 방식은 **Windows 10 (1903 이상)**, "커서 캡처"는 끄기
     - **화면 캡처(디스플레이 캡처)는 쓰지 마세요.** 다른 작업 화면이 녹화됩니다.
     - 믹서에서 **데스크톱 오디오와 마이크는 음소거**합니다.
3. 이 폴더를 PC에 내려받고 **`start.bat`을 더블클릭**합니다.
   처음에는 필요한 패키지를 설치하고 `config.toml`을 만듭니다. 창을 닫고 `config.toml`에 OBS 비밀번호를 적은 뒤 다시 실행하세요.
4. 절전 모드와 모니터 꺼짐을 해제합니다 (`설정 → 시스템 → 전원`). 모니터가 꺼지면 캡처가 검게 나올 수 있어요.
5. **녹화용 브라우저에서 사이트에 로그인**: 녹화 전용 브라우저는 평소 브라우저와 프로필이 따로라 로그인이 따로 필요합니다.
   폰에서 해당 사이트 주소로 녹화를 한 번 시작해 PC에 뜬 창에서 로그인해 두면 계속 유지됩니다 (`data/browser-profile`).

> 윈도우 시작 시 자동 실행: `Win+R` → `shell:startup` → `start.bat`의 바로가기를 넣어 두세요.

## 2. 밖에서 접속: Tailscale (무료, 포트 열기 불필요)

1. PC와 폰에 [Tailscale](https://tailscale.com/download)을 설치하고 같은 계정으로 로그인합니다.
2. 안드로이드 앱은 이것으로 끝입니다 (페어링 때 Tailscale 주소가 자동 저장됨).
3. 앱 없이 브라우저로 쓰려면 PC의 PowerShell에서 한 번 `tailscale serve --bg 8765`를 실행하세요.
   `https://<PC이름>.<tailnet>.ts.net` 주소가 생깁니다.

> 공유기 포트포워딩으로 인터넷에 직접 여는 것은 권장하지 않습니다.

## 녹화 격리: 다른 작업을 해도 녹화본은 깨끗하게

| 문제 | 해결 |
|---|---|
| 내가 쓰는 브라우저의 탭이나 소리가 섞임 | 녹화 전용 브라우저를 **별도 프로필, 독립 창**으로 띄웁니다. |
| 다른 창으로 가리면 영상이 멈추거나 검게 나옴 | 가려진 창의 재생/그리기를 줄이는 크롬 절전 기능을 끄고 실행합니다. |
| 키보드 ⏯ 미디어 키를 누르면 녹화 영상이 멈춤 | 녹화용 브라우저는 미디어 키에 반응하지 않습니다. |
| 녹화를 시작하면 브라우저가 튀어나와 작업을 방해함 | 창이 뜨면 바로 **맨 뒤로 보내고 작업하던 창으로 포커스를 돌려줍니다.** |
| 실수로 녹화 창을 최소화하면 캡처가 멈춤 | 최소화를 감지하면 포커스를 뺏지 않고 **맨 뒤에 다시 복원합니다.** |
| OBS가 엉뚱한 창이나 소리를 잡음 | 띄운 창을 OBS 소스에 **정확히 지정합니다.** |
| 설정 실수 (화면 캡처, 데스크톱 오디오 등) | 앱의 **"녹화 격리 점검"**에서 경고합니다. |

**팁**
- 평소 **크롬**을 쓴다면 녹화는 **엣지**로 하세요 (`browser.executable`). 실행 파일이 달라서 가장 확실합니다.
- 보조 모니터가 있다면 `window_position`으로 녹화 창을 그쪽에 두면 편합니다.
- 영상이 창에 이상하게 채워지는 사이트가 있으면 `fill_video = false`로 끄고 OBS 소스를 크롭하세요.

## 설정 (`config.toml`)

| 항목 | 설명 |
|---|---|
| `obs.video_source` / `audio_source` | 녹화 창에 자동으로 연결할 OBS 소스 이름 |
| `browser.executable` | 녹화에 쓸 브라우저. 비우면 크롬 → 엣지 순서로 찾음 |
| `browser.window_size` / `window_position` | 녹화 창 크기와 위치 (녹화 해상도) |
| `browser.fill_video` | 영상을 창에 꽉 채우기 |
| `browser.send_to_back` | 창을 띄운 뒤 맨 뒤로 보내고 포커스 복귀 |
| `browser.close_on_stop` | 녹화가 끝나면 녹화 창 닫기 (다음 화 자동재생 방지) |
| `recording.rename_to_title` | 녹화가 끝나면 파일 이름을 제목으로 |

## 개발

```bash
pip install -r requirements.txt pytest httpx
python -m recorder --demo     # OBS·브라우저 없이 화면 확인 (가짜 녹화기)
python -m pytest
```

- `recorder/server.py`: HTTP API (`/api/*`는 `Authorization: Bearer <토큰>` 필요, 앱 연결용 `/api/info`, `/api/pair/*` 제외)
- `recorder/core.py`: 녹화 흐름 (페이지 열기 → 위치 맞추기 → 녹화 → 끝나면 정지 → 이름 바꾸기)
- `recorder/browser.py`: 녹화용 브라우저 조작 (Playwright, iframe 속 플레이어 포함)
- `recorder/isolation.py`: 창 제어(Win32), OBS 격리 점검
- `recorder/obs.py`: OBS WebSocket v5 제어
- `recorder/pairing.py`: 앱 연결 (PC 정보, LAN 자동 검색, PIN 페어링)
- `recorder/static/`: 리모컨 웹 화면 (안드로이드 앱 안에서도 이 화면을 씀)
- `android/`: 안드로이드 앱 (Kotlin, Compose). `.github/workflows/android.yml`이 APK를 빌드해 Releases에 올림
